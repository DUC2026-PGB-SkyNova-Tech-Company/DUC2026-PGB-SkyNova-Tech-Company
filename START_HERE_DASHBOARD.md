## ⚡ Quick Start (2 Steps!)

### Step 1️⃣: Start the Server
Open your terminal and run:
```bash
npm start
```

### Step 2️⃣: Open Your Browser
Go to:
```
http://localhost:3001
```

**That's it!** 🎊 Your dashboard is now live!

## 📱 Access from Your Phone

1. **Find your computer's IP:**
   ```bash
   ipconfig
   ```
   Look for "IPv4 Address" (e.g., 192.168.1.100)

2. **On your phone's browser:**
   ```
   http://YOUR_IP:3001
   ```
   Example: `http://192.168.1.100:3001`

## 🆘 Troubleshooting

### Dashboard not loading?
✔️ Check server is running (`npm start`)
✔️ Try `http://127.0.0.1:3001`
✔️ Check port 3001 is available

### No data showing?
✔️ Record transactions via Telegram bot first
✔️ Click refresh button
✔️ Check console (F12) for errors

### Telegram bot issues?
✔️ Check `.env` has valid `TELEGRAM_BOT_TOKEN`
✔️ See [SETUP_GUIDE.md](SETUP_GUIDE.md)

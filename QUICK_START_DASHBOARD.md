# 🚀 Quick Start - Web Dashboard

## Start in 3 Simple Steps!

### Step 1: Start the Server ⚡
```bash
npm start
```

You should see:
```
✅ All handlers registered
🚀 Server running on port 3001
🌐 Dashboard available at http://localhost:3001
🤖 Telegram bot is active
✅ Database initialized
```

### Step 2: Open Your Browser 🌐
Navigate to:
```
http://localhost:3001
```

### Step 3: Enjoy! 🎉
Your beautiful dashboard is now live!

## Troubleshooting

### Dashboard not loading?
1. Check if server is running (`npm start`)
2. Verify port 3001 is available
3. Try `http://127.0.0.1:3001`

### No data showing?
1. Record some transactions via Telegram bot
2. Click the refresh button
3. Check browser console (F12) for errors

### Telegram bot not working?
1. Check `.env` file has valid `TELEGRAM_BOT_TOKEN`
2. See [SETUP_GUIDE.md](SETUP_GUIDE.md) for bot setup

## Access from Other Devices

### From Phone/Tablet on Same Network
1. Find your computer's IP address:
   ```bash
   ipconfig
   ```
   Look for "IPv4 Address" (e.g., 192.168.1.100)

2. On your phone/tablet browser:
   ```
   http://YOUR_IP_ADDRESS:3001
   ```
   Example: `http://192.168.1.100:3001`
